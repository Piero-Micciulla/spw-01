# Stock-Up Checklist

SPW #9. A static, local-first set of 20 structured preparation checklists.

```sh
./dev stock-up-checklist
./check stock-up-checklist
./build stock-up-checklist
```

Checks and custom items are stored under `spw-stock-up-checklist-v1` in browser localStorage. No data is sent remotely. Ads, analytics, and affiliate links are disabled.
